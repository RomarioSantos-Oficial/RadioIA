Clima automático do Brasil

O clima aparece automaticamente com duas capitais brasileiras sorteadas e uma cidade brasileira aleatória. Os dados do Open-Meteo são atualizados a cada 5 minutos.

Fontes RSS, Atom ou API JSON pública (notícias e trânsito)

G1 (últimas, mundo, tecnologia/games, cultura e música), UOL, CNN Brasil, Poder360 e BBC News Brasil são consultados automaticamente a cada 15 a 18 minutos; manchetes antigas são removidas e substituídas pelas atuais. As fontes antigas marcadas como “Geral” foram convertidas para “Notícias”. APIs JSON podem retornar uma lista items/articles/results/data. Para uma API protegida, informe um token Bearer.
